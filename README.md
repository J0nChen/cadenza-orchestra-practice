# Orchestra Practice

An independent, static violin practice page. Open the published page on a phone,
tablet or computer. No Mac, installation or account is required to use it.

Pictures at an Exhibition currently has approximate bar-following for the first
Promenade, Gnomus and the second Promenade. Later movements have movement jumps
only. Gnomus remains an uncertain trial. Liadov's Baba Yaga uses the existing
video-assisted timing. These are practice aids, not verified transcriptions.

The original part images remain visible. Tap a printed bar to seek, choose a
movement, change playback speed or loop a section. Timing adjustments remain
in the visitor's browser and can be exported. No visitor data is sent to a server.

This repository contains only the public practice page and its required media.
It is separate from the private Cadenza project and research.

Recording sources supplied for practice:

- Pictures at an Exhibition: https://www.youtube.com/watch?v=O31KPk5xnBg
- Liadov Baba Yaga: https://www.youtube.com/watch?v=17szhwbiw_o

Score images originate from the supplied IMSLP parts. Original recordings,

works is claimed here.
